# Troubleshooting

| Symptom                                      | Action                                                                                                                                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Jest says its React Native preset moved      | Use the current repository and run npm ci. @react-native/jest-preset@0.88.1 is now an explicit dev dependency.                                                                                  |
| SDK location not found                       | Install Android SDK and set ANDROID_HOME or generated android/local.properties with sdk.dir.                                                                                                    |
| Java/Gradle mismatch                         | Select JDK 17 in JAVA_HOME and Android Studio Gradle JDK settings; restart the terminal.                                                                                                        |
| SDK platform / Build Tools missing           | Install platform 37, Build Tools 37.0.0 and the pinned NDK via SDK Manager. See the pinned React Native version catalog.                                                                        |
| Gradle or Maven download fails               | Check your build computer's network/proxy. Initial builds need tool/dependency downloads. No paid service is necessary.                                                                         |
| Release missing signing variable             | Set all four VERDANT signing environment variables in the same terminal; regenerate Android. Do not switch to debug signing.                                                                    |
| APK signature conflict on install            | Use the same package and original key. Export a backup before removing a differently signed test build.                                                                                         |
| Launch says Metro unavailable                | You installed a development build. Start npm start on the same network, or build a signed release APK with embedded JS.                                                                         |
| JSON import fails                            | Use UTF-8 JSON without Markdown fences, comments or trailing commas. Read the field-specific validation messages. Check references, dates, time zone, weekdays and version.                     |
| Existing plan version rejected               | Export the current plan, preserve IDs, and set version above the latest stored version.                                                                                                         |
| No activities today                          | Check activation, schedule start/end, selected weekdays, interval, pause flag and plan time zone. Imported sample dates are literal; bundled sample selection rebases them to today.            |
| Today contains an old or removed activity    | Already tracked or moved records retain their historical snapshot. Untouched future records use the updated configuration.                                                                      |
| Reminder missing                             | Enable notifications in Settings and Android permission controls; check activity time, reminder toggle, lead time and quiet hours. Reopen the app to refresh the 14-day/60-reminder window.     |
| Reminders delayed                            | Android battery optimization, Doze, OEM background restrictions or force-stop can delay/suppress delivery. The app does not request exact-alarm access.                                         |
| Past date is marked missed                   | Pending instances from before the current plan-zone date are missed. Record the activity retrospectively if it was actually done.                                                               |
| Timer kept counting while closed             | Expected: elapsed time is computed from the persisted start timestamp. Pause when finished. System clock changes can affect elapsed time.                                                       |
| Cannot edit a measurement in its history row | Activity-linked measurements are edited through their source activity. Manual entries have a separate Edit action.                                                                              |
| Backup cannot restore                        | Use a full verdant-backup version 1 file, not a plan or progress archive. Files with broken references/unknown columns are rejected; the existing database remains. Maximum file size is 25 MB. |
| Share-to-app not listed in Expo Go           | Share-in requires the generated native Android project. Install a native build and share a local JSON/text file. Files apps vary in reported MIME types; use the in-app picker as fallback.     |
| Expo dependency check times out              | Network checks may be blocked. EXPO_OFFLINE=1 npx expo install --check uses bundled compatibility information; it does not check remote native-library metadata.                                |

Report bugs with device/Android/app versions, steps and a redacted configuration. Never post a real backup, health details or signing secrets. Export a backup before reinstalling or clearing storage.

If UI tests cannot find `test-renderer`, use the current package.json/lockfile and run npm ci. For an existing checkout, install test-renderer@1.3.1 as a dev dependency. It is a different package from react-test-renderer. If npm reports blocked scripts for esbuild/@parcel/watcher, review and approve those named packages using npm install-scripts approve, then run npm rebuild for those packages. The committed allowScripts policy already covers the pinned reviewed versions.

## Still seeing the DateField raw-text error

Use the complete fixed source from version 1.1 and follow [the Windows update guide](../UPDATING_WINDOWS.md). Verify the Settings footer version before debugging dependencies. Copy the contents of the inner source folder into the actual Metro project (`C:\v`), then restart with `npx expo start --clear`. The regression suite renders Today → QuickMeasurement → DateField, plus optional empty/populated date controls. A passing component test does not replace testing on your installed device.
